# java-racingcar-precourse

## 🚗 초간단 자동차 경주 게임

## 📌 프로젝트 소개

이 프로젝트는 자바(Java 21)를 사용하여 콘솔 환경에서 실행되는 간단한 자동차 경주 게임입니다.
사용자로부터 경주에 참여할 자동차 이름과 시도할 횟수를 입력받아 게임을 진행하며, 각 턴마다 무작위 조건에 따라 자동차가 전진합니다. 게임 종료 후 가장 많이 전진한 자동차(들)를 우승자로 선정하여 출력합니다.


## 🛠️ 기술 스택 및 개발 환경

언어: Java 21

개발 환경: IntelliJ IDEA

빌드 도구: Intellij IDEA

테스트: JUnit 5


## ⚙️ 실행 방법


#### 1. 전제 조건

Java Development Kit (JDK) 21, IntelliJ IDEA가 설치되어 있어야 합니다.


#### 2. 프로젝트 클론 및 실행

레포지토리 클론:

git clone [레포지토리 주소]

cd java-racingcar-8

git checkout -b {본인 아이디}


IntelliJ에서 실행:

IntelliJ IDEA를 열고 File > Open을 통해 클론한 디렉토리를 엽니다.

src/main/java 아래의 Application.java 파일을 찾아 실행합니다.


콘솔 입력:

프로그램이 시작되면 콘솔에 따라 아래 두 가지를 입력합니다.

경주할 자동차 이름 (쉼표로 구분, 이름은 5자 이하)

시도할 횟수 (이동 횟수)


## 📝 게임 규칙 및 기능 명세


#### 1. 자동차 이름 입력

자동차 이름은 쉼표(,)를 기준으로 구분하여 입력합니다. (예: pobi,woni,jun)

유효성 검사: 자동차 이름은 5자 이하여야 합니다. 5자를 초과하면 IllegalArgumentException을 발생시키고 애플리케이션을 종료합니다.


#### 2. 이동 횟수 입력

사용자는 몇 번의 이동을 할 것인지를 숫자로 입력합니다.


#### 3. 자동차 전진 조건

전진 여부는 0에서 9 사이의 무작위 값으로 결정됩니다.

무작위 값이 4 이상일 경우, 자동차는 1칸 전진합니다.


#### 4. 게임 결과 출력

각 턴이 끝날 때마다 현재까지의 **자동차 이름과 전진 거리**을 출력합니다.

ex)
pobi : -
woni : --
jun : -


#### 5. 최종 우승자 결정

주어진 횟수만큼 경주가 완료되면, 가장 멀리 이동한 자동차를 우승자로 선정합니다.

우승자가 여러 명일 경우, 쉼표(,)를 이용하여 모두 출력합니다.


#### 6. 예외 처리

사용자가 잘못된 형식이나 규칙에 맞지 않는 값을 입력할 경우, IllegalArgumentException을 발생시킨 후 프로그램이 종료됩니다.


## 🧱 프로젝트 구조 (클래스 설계)


클래스 | 역할 | 상세 내용


Input | 입력 처리 | 자동차 이름과 시도 횟수를 사용자로부터 입력받고 기본적인 유효성을 검사합니다.

Car | 각 자동차 상태 | 각 자동차의 전진 거리 상태를 변화합니다.

Spliiter | 문자열 변환 | 입력받은 자동차 문자열을 List<Car>으로 변환합니다.

Output | 출력 처리 | 게임 진행 상황 및 최종 우승자를 콘솔에 출력하는 역할을 담당합니다.

Main | 흐름 제어 | 전체 게임 로직을 조정하고 클래스 간의 흐름을 제어하는 메인 클래스입니다.

CarDTO | List<Car> 관리 | 자동차의 이름, 현재 위치(전진 거리) 상태를 관리합니다.

RandomValueCalculator | 랜덤값 계산 | 0~9 사이의 무작위 값을 생성하고, 이 값이 4 이상인지 판단하여 전진 여부를 결정합니다.

GameManager | 게임 핵심 로직 | 경주를 시작하고 진행합니다.
